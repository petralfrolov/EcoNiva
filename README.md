# Technoforge: AgroTECH - Трек 1: Анализатор рациона коров

## Описание проекта

Данный проект представляет собой решение для задачи Трека 1: "Выявление факторов в рационах коров, влияющих на жирнокислотный состав молочного жира".

Разработано десктоп-приложение с рекомендательной моделью, которое позволяет:

* Анализировать текущий рацион кормления коров на основе данных из отчетов (PDF, Excel) или ручного ввода.
* Прогнозировать жирнокислотный состав молока (лауриновая, пальмитиновая, стеариновая, олеиновая, линолевая и линоленовая кислоты) на основе состава рациона.
* Визуализировать состав рациона и прогнозные значения кислот с указанием целевых диапазонов.
* Формировать текстовые рекомендации по корректировке рациона, если прогнозные значения выходят за пределы нормы.
* Автоматически подбирать скорректированный рацион для достижения целевых показателей с помощью встроенного оптимизатора.

## Техническое описание

* **Интерфейс:** Streamlit — для создания интерактивного веб-приложения.
* **Обработка данных:** Pandas, NumPy — для парсинга, очистки и агрегации данных из отчетов. pdfplumber и openpyxl используются для чтения PDF и Excel файлов соответственно.
* **Моделирование:** Statsmodels — для построения и анализа регрессионных моделей. Для каждой из шести жирных кислот была обучена отдельная модель множественной линейной регрессии (OLS), использующая в качестве предикторов агрегированные группы кормов и их доли в рационе.
* **Визуализация:** Plotly — для построения интерактивных графиков (древовидная диаграмма рациона и столбчатая диаграмма прогнозов).

## Установка и запуск

**Требования:**

* Python 3.9+

1. Клонируйте репозиторий:

   ```bash
   git clone <URL вашего репозитория>
   cd <папка репозитория>
   ```

2. Установите зависимости:
   Убедитесь, что у вас установлен pip. Выполните команду для установки всех необходимых библиотек из файла requirements.txt.

   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:

   ```bash
   streamlit run app.py
   ```

После запуска в вашем браузере откроется вкладка с приложением.

## Инструкция пользователя

### Загрузка данных:

* На боковой панели слева нажмите на кнопку "Загрузите рацион" и выберите файл в формате .pdf или .xlsx.
* Приложение автоматически обработает файл, сгруппирует компоненты и заполнит поля ввода их массами в килограммах сухого вещества (кг СВ).
* В блоке "Логи разбора файла" можно посмотреть детальную информацию о процессе парсинга в случае возникновения ошибок или неточностей.

### Ручной ввод и корректировка:

* Вы можете вручную изменять значения для каждого компонента рациона в полях ввода на боковой панели. Любое изменение автоматически учитывается в инфографике дашборда.

### Анализ результатов:

* **Структура рациона:** На основном экране график "Treemap" показывает долю каждого компонента в общем объеме сухого вещества.
* **Сумма СВ:** Метрика показывает общее количество сухого вещества. Она подсвечивается зеленым, если находится в пределах нормы (15-30 кг), и красным, если выходит за них.
* **Прогноз по кислотам:** Набор метрик вверху показывает прогнозное среднее значение для каждой кислоты и ее статус (🟢 Норма, 🟡 Риск отклонения, 🔴 Вне нормы). Основной график ниже детально визуализирует прогноз (точка), доверительный интервал 95% (черная линия) и целевой диапазон (зеленая область).

### Рекомендации и автоподбор:

* Если прогноз по какой-либо кислоте отклоняется от нормы, появляется блок с текстовыми рекомендациями, предлагающий, какие компоненты рациона следует увеличить, а какие — уменьшить.
* **Автоподбор:** Нажмите кнопку "Автоподбор" на боковой панели. Алгоритм предложит скорректированный рацион, который приводит прогнозные значения кислот в норму.
* **Фиксация компонентов:** Вы можете "заблокировать" некоторые компоненты, поставив галочку 🔒 рядом с ними. Заблокированные компоненты не будут изменяться при автоподборе. Кнопка "Разблокировать всё" снимает все блокировки. Также можно заблокировать сухой вес, при этом алгоритм попробует ребалансировать рацион, не изменяя сумму СВ.

### Анализ чувствительности:

* В нижней части страницы находится таблица "Интерпретация". Она показывает, как изменится (в процентах) содержание каждой кислоты при добавлении 1 кг СВ соответствующего компонента рациона. Красный цвет означает положительное влияние, синий — отрицательное.
* Для интерпретации применён метод локальных производных. Так как в модели используются преобразованные факторы, Δ% по кислотам может меняться при изменении компонентов рациона.
